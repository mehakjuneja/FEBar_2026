# docs/presentation/ — Deck & roleplay artifacts

The FE Bar's second required element is the **customer-facing AI roleplay** (business + technical
personas), and a **presentation deck** is a submission artifact (attached as **PDF**).

- **Plan:** [`../superpowers/plans/2026-09-24-phase6-presentation-roleplay.md`](../superpowers/plans/2026-09-24-phase6-presentation-roleplay.md) (R1 deck, R2 business prep, R3 technical prep).
- **This folder** will hold the built artifacts: the deck outline/source, the exported PDF, and the
  per-persona prep + Q&A banks.

**Deck tooling options:** `fe-google-tools:google-slides` (Databricks template) → export PDF, or
`fe-workflows:markdown-to-pdf` for a fast branded PDF from markdown.

**Remember:** the roleplay is scored on demo setup, value communication, reading the room, and
professionalism — and it's where you *defend* the decisions logged in the spec (§10).
